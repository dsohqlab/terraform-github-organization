# Complete

Configure Github Organization

## Requirements

The example requires two environment variables to work. Those are

1. `GITHUB_TOKEN`: Github Access Token with organization resource access permissions.
2. `GITHUB_OWNER`: Github Organization name.

## Usage

To run this example you need to execute:

```bash
terraform init
terraform plan
terraform apply
```

> **Note:** This example may create resources that incur charges on your Github bill. Run `terraform destroy` when you no longer need these resources.
